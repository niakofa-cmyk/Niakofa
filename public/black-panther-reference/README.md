# Black Panther Spirit Animal Reference Set

These source images were supplied for the Niakofa Black Panther/African leopard spirit-animal artwork. They are retained here as visual references for future vector, Rive, Lottie, and Sprite360 work.

- `01-official-asset-pipeline.png` — official multi-view asset pipeline sheet
- `02-leaping-reference.png` — high-contrast leaping pose
- `03-navigation-composite.png` — app/navigation placement reference
- `04-crouching-reference.png` — crouching/pounce pose
- `05-vector-layer-reference.png` — layer separation reference
- `06-additional-reference.png` — additional supplied pose reference

The implementation uses original SVG geometry and does not embed these raster references in the runtime bundle.
