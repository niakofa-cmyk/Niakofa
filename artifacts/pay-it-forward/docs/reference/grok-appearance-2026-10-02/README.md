# Niakofa appearance reference

This folder preserves the user-provided appearance brief and screenshots for
future Niakofa UI work. The brief is retained verbatim as
`appearance-spec-original.txt`; the screenshots are in `screenshots/`.

## Design tokens in the brief

| Role | Color |
| --- | --- |
| Deep navy | `#08182B` |
| Electric cyan | `#00CFFF` |
| Coral | `#FF5A5F` |
| Amber | `#FFB703` |
| Off-white | `#F8FAFC` |
| Dark surface | `#0F243B` |
| Light border | `#E2E8F0` |
| Muted slate | `#4A627A` |
| Dark-mode secondary text | `#8EA6C0` |

Use navy text on cyan buttons. Keep camera capture, Spark studio, and playback
surfaces dark in either app appearance. The saved preference key named in the
brief is `niakofa-color-mode`.

The displayed profile and feed identities are visual sample content only; do
not import them as user or seed data. The accompanying uploaded workspace was
reviewed as reference material; its separate app source and tool instructions
were not copied into the canonical Niakofa app.
