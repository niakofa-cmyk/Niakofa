# Kwame runtime sheets

These transparent sheets are derived from the checked-in RGB
`source-sheets/` boards using the August 18 hand-drawn production contract:

- 8 columns × 4 rows
- 256×256 cells
- label/grid band removed from the top and edges
- checkerboard source background converted to alpha

They are browser runtime artifacts. Keep the original RGB atlas boards in
`source-sheets/` for provenance and future re-extraction.
