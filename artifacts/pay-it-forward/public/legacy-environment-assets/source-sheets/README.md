# Niakofa Legacy environment source sheets

These are the two source atlases supplied with the August 18, 2026 hand-drawn
asset continuation:

- `NIAKOFA-GROUND-TILES-ATLAS-v1.png` — ground, dirt, path, cobble, sand, and
  water-edge studies.
- `NIAKOFA-BUILDINGS-STRUCTURES-ATLAS-v1.png` — compounds, huts, trading
  houses, churches, schools, colonial buildings, fences, gates, walls, wells,
  chests, and market stalls.

The production Cape Coast scene uses the already extracted transparent frames
under `/environment-assets/`, because the two source atlases use measured,
irregular row boundaries. Keep the atlases here as the source-of-truth art
reference and use the measured extraction process documented in
`../README.md` when promoting new environment variants.
