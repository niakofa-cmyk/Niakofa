# Circles visual reference

This artifact is a non-production visual reference for Circles/Spirals layout
and interaction exploration.

- It uses mock data and local room state.
- Its build intentionally does not produce a deployable application.
- The root build and deployment paths explicitly exclude it.
- Production Circles use the canonical Niakofa React app, API contracts, and
  LiveKit media boundary under `artifacts/pay-it-forward/` and
  `artifacts/api-server/`.

Do not add production routes, credentials, database migrations, provider
configuration, or realtime signaling to this artifact.
