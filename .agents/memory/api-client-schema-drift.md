## Rule
The `User` type in `lib/api-client-react/src/generated/api.schemas.ts` is generated by orval and says "Do not edit manually". It is missing `helper_skills` (TEXT[] on the users table), which IS returned by the backend via `userSelect`.

When accessing `helper_skills` from a typed `User` object, cast via `(user as any).helper_skills` and document why.

**Why:** Orval regenerates from the OpenAPI spec. `helper_skills` was never added to the spec. Editing the generated file would be overwritten on next codegen.

**How to apply:**
1. Use `(user as any).helper_skills` with an explanatory comment.
2. Use explicit length-check fallback, NOT `??`: `(hk && hk.length > 0) ? hk : fallback`. The `??` operator only gates on null/undefined; an empty array `[]` is truthy and would silently block the fallback, hiding skills for migrated/partially-synced users.
3. Long-term fix: add `helper_skills` to the OpenAPI spec and re-run orval to eliminate the casts.
