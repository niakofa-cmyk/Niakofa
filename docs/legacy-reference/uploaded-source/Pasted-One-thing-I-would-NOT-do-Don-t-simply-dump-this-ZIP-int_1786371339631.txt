What do SV / TV / TVD actually mean?
This is important for the House of Mensah demo.
Face
These are the portrait components.
For example:

FG_Face
FG_Eyes
FG_Eyebrows
FG_Mouth
FG_Nose
FG_FrontHair
FG_RearHair
FG_Clothing
FG_Beard
FG_Glasses
FG_AccA
FG_AccB

These can be layered into a character portrait.

TV
Top-view / map character.
This is the actual little character walking around the RPG world.
The standard format is a 144×192 spritesheet, containing 48×48 frames.
So this is what you could use for:
Kwame walking through the Mensah compound.

SV
Side-view battle character.
These are larger animated character sheets used for side-view battle presentation.
The standard format is 576×384, with 64×64 frames.
This matters if you decide to include combat.
For your current House of Mensah concept, though, combat isn't necessary.

TVD
Top-view damage/downed character.
These are used for the alternate map-state sprite.
The standard format is 144×48, with 48×48 frames.

Variation
These are the little thumbnail icons used to select generator parts.
For example:

icon_Eyes_p04.png
icon_Nose_p05.png
icon_Mouth_p21.png
icon_RearHair_p10.png
icon_Clothing_p14.png

The documented generator format uses these as the selectable variation previews.
