# Exact session upload snapshot

This directory preserves the exact seven files uploaded for the August 12,
2026 Niakofa Legacy production-readiness pass. The two ZIP files are retained
as reference archives; their runtime assets are not copied wholesale into the
browser bundle.

The supplied guidance establishes these boundaries:

- keep Niakofa's Family Vault and knowledge graph authoritative;
- use a Niakofa-native runtime instead of embedding RPG Maker's `rpg_*.js`
  architecture;
- curate assets by House of Mensah scene and era;
- reuse locations across generations so collapse and migration are world-state
  changes, not unrelated maps;
- keep generic fantasy and source-heavy material libraries out of production;
- preserve explicit, evidence-backed character appearance data.

The application uses the original-art character layers already promoted under
`artifacts/pay-it-forward/public/legacy-world-assets/`. The generator-backed
library remains an opt-in compatibility path with its existing licensing
review boundary.
