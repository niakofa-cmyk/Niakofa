
But I found the missing piece
The client deliberately skips sending a location update if the user hasn't moved far enough.
That is good for battery/API efficiency, but it creates a problem for "Who is currently here?"
A person sitting at a Diaspora event for 30 minutes may still be physically there, but the database has no dedicated GPS freshness timestamp proving that.
users.updated_at cannot solve this because normal profile edits also change it.

New model
GPS → server timestamp → nearest verified Diaspora hub → live presence count → Globe/Dashboard
A user's raw coordinates never get returned by the new presence endpoint.
Instead the server derives:
Current hub: Fort Worth, TX GPS fresh: 42 seconds ago Live users in this hub: 7
No names, addresses, or coordinates are exposed.
New freshness boundary
A user is considered "live" only if their server-synced GPS is ≤10 minutes old.
That means:
* stale user → excluded
* user who leaves the area → eventually disappears
* user who closes the app → eventually disappears
* stationary user → remains present because of the heartbeat
* user in another city → belongs to that hub instead
* user outside every hub radius → not assigned to a Diaspora hub
Hub radius
I added presence_radius_km.
This is intentionally not a legal boundary and not a fake neighborhood polygon.
It is an operational matching radius that administrators can tune per Diaspora hub.
Default: 35 km.
That's deliberately conservative for Fort Worth so Dallas isn't accidentally presented as Fort Worth presence.

New live endpoint
The package adds:
GET /api/griot/live-presence

    }

That gives Diaspora a real physical-presence layer without turning the Globe into a surveillance map.

I also fixed the stationary-user freshness problem
The existing GPS watcher has movement thresholds.
The enhancement adds a 60-second heartbeat:

moved enough?
    yes → sync
    no
      ↓
heartbeat older than 60 sec?
    yes → sync
    no → skip

So someone sitting in a neighborhood doesn't vanish from the live count simply because they're sitting still.

Your Spiral work and Diaspora work should remain separate geographically.

* 0

* 6–20

or a minimum threshold before showing exact presence.
