How to verify 30–60+ minutes
Don’t rely on “it felt fine.” Run a timed sampler:
Every 5–10s log: connection/ICE state, track live, packets/jitter/RTT, frames, reconnect count, JS heap.
60‑minute pass bar (from your doc):
* Audio availability ≥ 99.9% (no sticky mute/echo/dup after reconnect)
* Video ≥ 99.5% when camera expected on (no permanent freeze/orphan tracks)
* Network blip → auto-recovery within a defined window
* Memory/CPU not runaway
Also run hostile conditions (Wi‑Fi↔cellular, tab background, mute/camera toggles, host blip) and several Circles at once while measuring API/WS load—not media through Node.

TypeScript

import { CircleEnduranceCollector, downloadEnduranceReport } from "@/lib/circleEnduranceMetrics";

const endurance = new CircleEnduranceCollector({
  sessionId,
  getPeerConnections: () => meshRef.current?.getPeers() ?? new Map(),
  getLocalStream: () => localStream,
  getConnectionLabel: () => mediaConnectionState,
  getReconnectCount: () => reconnectCount,
  expectAudio: () => true,
  expectVideo: () => !!session?.video_enabled && videoOn,
});
endurance.start();
// after 60 min or on leave:
downloadEnduranceReport(endurance.stop());
