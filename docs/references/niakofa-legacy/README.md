## Runtime boundary

The production runtime uses only the reviewed, explicit assets under
`artifacts/pay-it-forward/public/legacy-character-assets/` and
`artifacts/pay-it-forward/public/environment-assets/`. Reference ZIP contents
must not be served directly or treated as verified family likenesses.

The first authored hostile encounter is the scene-owned Road Raider at the
Mensah Compound front gate. Its damage, defeat, reward item, and quest echo are
wired through the existing Legacy world state rather than through a second RPG
runtime.
