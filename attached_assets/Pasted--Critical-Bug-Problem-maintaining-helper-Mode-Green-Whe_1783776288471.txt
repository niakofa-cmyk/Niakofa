One thing I'd fix before this ships further
The repayment-plan and pay-from-wallet endpoints, and the no_show_count field, are not in lib/api-spec/openapi.yaml. Your project's own README calls the OpenAPI spec "the single source of truth" and says "never hand-write types that codegen produces" — but that's exactly what happened here: the frontend calls these with raw fetch() instead of the generated, type-checked React Query hooks. It works today, but it means:
* No compile-time safety if the request/response shape drifts
* Future codegen runs won't know these endpoints exist
* Anyone extending this later has to read route code instead of the contract
Recommendation: backfill these three into the OpenAPI spec and run pnpm --filter @workspace/api-spec run codegen, then swap the raw fetch() calls for the generated hooks. Low effort, meaningfully reduces future drift risk.
