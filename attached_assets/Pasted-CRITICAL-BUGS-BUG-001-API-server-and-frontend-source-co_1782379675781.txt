BUG-002 — post-merge.sh runs pnpm --filter db push which is UNSAFE in production
File: scripts/post-merge.sh

pnpm --filter db push   # drizzle-kit push — destructive, no migration file, no rollback

drizzle-kit push applies schema changes directly to the database without generating migration files. It can DROP columns and tables silently. This runs automatically post-merge on Replit. Should be drizzle-kit generate + drizzle-kit migrate.

BUG-003 — seed-if-empty.ts dynamic import uses .js extension for a .ts file
File: scripts/src/seed-if-empty.ts

const seedModule = (await import("./seed-fort-worth.js")) as { default?: unknown };

Imports seed-fort-worth.js but the file is seed-fort-worth.ts. In a type: "module" + tsx/ts-node environment without explicit allowImportingTsExtensions, this will either silently succeed (if compiled first) or throw ERR_MODULE_NOT_FOUND at runtime. The module is also typed with as { default?: unknown } when seed-fort-worth.ts has no default export — it runs as side effects on import. The runSeed path will always be undefined, and the else branch fires — meaning the re-import via dynamic import just double-runs the seed script's side effects uncontrollably.

BUG-004 — niaMemoriesTable uses user_id as PRIMARY KEY — one memory per user
File: lib/db/src/schema/nia-memories.ts

user_id is the primary key. Every user can only have one memory row. Any upsert that adds a second memory for the same user will either fail or overwrite the entire memory field. If the intent is to store a single growing memory blob per user, this may be intentional — but there is no length cap on the text("memory") column, no truncation logic, and no versioning. Unbounded memory growth will degrade Nia's context window and API costs.

BUG-019 — orval.config.ts uses useDates: true and useBigInt: true in Zod output
File: lib/api-spec/orval.config.ts

useDates causes Orval to generate z.coerce.date() for date fields. The API returns ISO strings. z.coerce.date() will parse them into JS Date objects, but customFetch returns raw JSON without date coercion.
