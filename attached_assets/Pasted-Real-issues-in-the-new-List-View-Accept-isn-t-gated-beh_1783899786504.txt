Real issues in the new List View
"Accept" isn't gated behind Helper Mode. Every other claim surface in this file enforces it: BottomSheet only renders when helperModeActive, and even the WebGL-fallback list disables the button and shows "Switch to Helper Mode in the top bar to claim requests" when it's off. RequestListView skips that check entirely — RequestCard's Accept button is always live regardless of helperModeActive, so a requester who taps into List view sees a fully clickable "Accept" that doesn't match how claiming works everywhere else in the app.
Tapping Accept while logged out is a silent no-op. handleClaim in map.tsx is just if (!currentUser) return; — no feedback, no redirect. That's been true since the very first version, but it was low-risk before because BottomSheet (the only place using it) only ever renders for an already-signed-in helper. Now RequestListView is reachable by anyone in any mode, so this silent-swallow path is actually exposed to users for the first time. The WebGL-fallback list already has the right pattern (if (!currentUser) { setLocation("/login"); return; }) — I'd apply that same guard to handleClaim directly so every caller gets it for free, rather than patching each call site.
List view has no way to post a new request. The "Request Help" FAB is now gated viewMode === "map", so a non-helper who switches to List view (to browse, say) loses their one entry point for creating a request until they switch back. Worth either keeping the FAB visible in both modes, or giving RequestListView its own equivalent affordance.
Smaller polish items on the address search

No click-outside-to-dismiss and no Escape-key handling — right now the only way to close it is the toggle button or picking a suggestion. Minor, but common expectation for a search overlay.
No affordance to clear a selected address and snap back to "my location" once you've searched somewhere else — you already have recenterOnMe, which clears searchCenter; it'd be a one-line win to surface that same action from inside the open search bar, not just the map's Recenter button underneath it.
