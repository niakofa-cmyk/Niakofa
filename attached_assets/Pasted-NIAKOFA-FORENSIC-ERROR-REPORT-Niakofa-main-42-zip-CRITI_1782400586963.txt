NEW SECURITY ISSUE — cross-user Nia chat history disclosure
artifacts/api-server/src/routes/nia-proxy.ts, GET /nia/history/:sessionId
The ownership check is:
if (userId !== undefined && !sessionId.startsWith(...) ...) return 403;
This route uses parseAuth (optional — never rejects, never 401s), not requireAuth. When no Bearer token is sent at all, req.authenticatedUserId is undefined, so userId !== undefined is false and the entire ownership check is skipped. Any unauthenticated caller who knows or guesses a userId-uuid-format session ID can read another user's full Nia conversation history with zero authentication. The check only activates for callers who are logged in — anonymous requests bypass it entirely. This needs requireAuth (or an explicit reject-when-anonymous branch) on this route.
