1. Implements POST /requests/:id/rate — the endpoint RatingModal.tsx has been calling this whole time with nothing on the other end. It:
    * Requires auth only (not requireApproved — leaving a rating is an opinion about a past job, not a money-moving action, so a suspended account can still submit one).
    * Only allows rating after the request's real status, "completed" (I checked — not "complete", which is what I'd have assumed without reading the actual /complete handler).
    * Derives role and the ratee server-side from request.requester_id/helper_id — never trusts the client, consistent with how this file treats every other identity field. The frontend's role prop is just display copy; it was never even in the POST body.
    * Returns the exact string "You have already rated this request" on a duplicate, matching what RatingModal.tsx already special-cases to show its "already submitted" state instead of an error toast.
    * Validates stars (1–5) and review (≤500 chars) with a local zod schema.
