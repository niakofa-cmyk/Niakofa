Build production-quality master SVG asset, not simply an illustration. A true asset matching the reference would consist of thousands of Bézier control points, hundreds of feather paths, gradients, masks, clipping paths, filters, symbols, and a complete animation-ready layer hierarchy. 
The best way to build it is as a modular vector asset rather than trying to generate one enormous SVG in one:
The finished deliverable should include:
* Master SVG (100% vector)
* Layered Illustrator (.AI)
* SVG with preserved layer names
* Figma version
* Animation-ready SVG
* Separate feather symbols
* Gradient library
* Color palette
* Motion pivots
* Bone hierarchy
* LOD versions
* JSON animation rig
* Flutter-ready asset
* Rive-ready asset
* Lottie-ready asset

Animation rules:
* Primary feathers move first.
* Secondary feathers lag.
* Coverts lag behind secondaries.
* Body moves last.
* Egg remains upright using neck compensation.
* Tail bends independently.
* Body never rotates the egg.
Visual effects:
* Idle → teal glow
* Helping → gold shimmer
* Celebrate → gold particles + egg pulse
* Notification → teal pulse
* Walking → teal dust particles
