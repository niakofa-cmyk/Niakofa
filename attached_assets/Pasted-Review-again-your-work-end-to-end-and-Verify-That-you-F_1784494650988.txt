Audit Approach
Ran 5 parallel subagent audits covering Audio Circles, Griot Stories, Admin Panel, Wallet/Payments, and Community Hub simultaneously, then two more targeted rounds for deeper diagnosis. Found 5 actionable gaps.

Gap 1 — Tip endpoint was a 410 stub (money dead-end)
Problem: TipModal.tsx called POST /requests/:id/tip which returned 410 Gone — no tip could ever succeed.
Fix: Added POST /requests/:id/tip-wallet that:
* Atomically debits the requester's wallet and credits the helper's wallet
* Writes tip_sent + tip_received ledger rows (both as plain text type — no enum constraint)
* Returns 402 + { code: "insufficient_balance" } on low balance
* Notifies helper via sendToUser(payment_completed) WS event
* Updated TipModal.tsx to call the new route; on 402 redirects to /wallet?tip_amount=X&... so user can add funds first

Gap 2 — No DELETE /griot/stories/:id
Problem: Authors could not delete their own stories. The route simply didn't exist.
Fix: Added DELETE /griot/stories/:id — author-or-admin check (in-handler DB lookup, not middleware), hard delete with 403/404 guards.

Gap 3 — Transaction history hard-capped at 50 with no way to see more
Problem: GET /users/:id/transactions had a hardcoded .limit(50) and no offset support; wallet UI showed no "Load more" button.
Fix:
* API now accepts ?limit (1–100) and ?offset — returns backward-compat Transaction[] body (preserving the generated client) + X-Total-Count / X-Has-More headers
* wallet.tsx replaced the generated hook with a manual paginated fetch + "Load more" button that appends the next page; all post-action refreshes now call fetchTransactions(0, false) instead of the invalidated query key

Gap 4 — No way to grant/revoke admin from the admin panel
Problem: is_admin flag existed in the DB and controlled access, but no UI or API existed to toggle it. Admins had to manually edit the database.
Fix:
* Added PATCH /users/:id/toggle-admin backend route (admin-only, cannot self-demote — returns 409)
* Added "Grant Admin" / "Remove Admin" button to the UsersTab action sheet in admin.tsx with optimistic UI update

Gap 5 — iOS font-size zoom on TipModal custom amount input
Fix: Added style={{ fontSize: "16px" }} to the custom amount <input> in TipModal — prevents iOS Safari auto-zoom on focus.
