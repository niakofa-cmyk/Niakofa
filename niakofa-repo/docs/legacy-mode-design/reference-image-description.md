# Legacy Mode — Reference Image Description

The reference image for the Niakofa Legacy Mode shows a game start screen with the following elements:

## Start Journey Screen

The screen features a dark, warm-toned background (deep browns and golds) with:

1. **"START JOURNEY"** heading at the top
2. **Narrative intro text**: "Tonight, you will walk in the footsteps of someone who came before you."
3. **Ancestor card** showing:
   - "Your ancestor" label
   - Name: "Ama Serwaa"
   - Born: 1898
   - Location: Cape Coast
   - Age: 14
   - Stats: "Known family memories: 8, Recorded stories: 3, Known locations: 5"
4. **Chapter card** showing:
   - "CHAPTER I"
   - "Before the Journey"
   - Description: "Your family remembers that Ama loved school, but her father expected her to help with the family business..."
5. **"BEGIN"** button at the bottom

## First Playable Chapter

The chapter scene shows:
- Year: 1898
- Location: Cape Coast
- Time: Morning
- Narration: "Ama wakes before sunrise. Her mother is preparing breakfast. Her father has already gone to the market. Today is different. Today Ama must decide..."

This represents the moment where family-specific information enters the story, making Niakofa a game rather than just a data app.
