# Niakofa Legacy Mode UI Reference

## Reference Image
`diaspora-reference.png` — Full Legacy Mode RPG design mockup

## What This Image Shows

This reference screenshot is the **target UX vision** for the Niakofa Legacy Mode — the Living Family RPG. It shows the complete game interface:

### Top Section — Legacy Home
1. **Header** — "Niakofa Legacy" with Timeline and Awards buttons
2. **Progress Hero** — Circular SVG ring showing % Legacy Complete, with Families/Ancestors/Stories counts
3. **Game Modes** — 2×2 grid: Legacy Mode, Exploration Mode, Family Quests, Reunion Mode
4. **Active Ancestor** — Character card with Health/Knowledge/Reputation stat bars

### Middle Section — Game World
5. **World Map** — Horizontal scroll of stages: Ancestral Village → Mission School → Colonial Town → New Opportunities
6. **Characters** — Family tree members as playable ancestor cards with avatars
7. **Active Quest** — AI-generated quest card with XP rewards, category, and "Start Quest" button
8. **Inventory** — Tabbed view: Memories | Items | Artifacts

### Bottom Section — Progression
9. **Achievements** — Badge progress: Story Keeper, Roots Explorer, Family Connector, Legacy Builder
10. **Oral Story Recording** — Waveform visualization, prompt cycling, record/stop controls
11. **Progress Dashboard** — Landscape background with 4-stat grid (Stories, Relatives, Families, Quests)
12. **Family Reunion Challenge** — Cooperative multiplayer with leaderboard
13. **Family Vault Quick Access** — 4-icon grid: Photos, Stories, Audio, Docs
14. **Preserve the Culture** — Card game CTA

### Achievements Page (/legacy/achievements)
- 8 achievement cards with progress bars
- Skill tree with locked/unlocked skills
- Legacy inventory collectibles grid
- Nia AI integration prompts

## Design Tokens
- Background: warm dark brown `#1A0F08`
- Card surfaces: `#2A1A0F`
- Inner cards: `#3A2A1A`
- Gold accent: `text-amber-400` / `bg-amber-500`
- Stats: Health=rose, Knowledge=blue, Reputation=amber
- Borders: `border-amber-900/30`
