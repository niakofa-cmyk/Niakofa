Diagnosis & Fix
The error
Current environment does not allow unsafe-eval, please use pixi.js/unsafe-eval module to enable support
is the standard PixiJS v8 + Content-Security-Policy failure. Your production host (or browser extension / strict CSP) blocks new Function / eval. PixiJS v8 requires an explicit import of its CSP-safe path.
Recent commits already improved boot resilience (LegacyGameCanvas timeout + retry), but the unsafe-eval import is still missing (or not first).

1. Immediate Fix (do this first)
In artifacts/pay-it-forward/src/legacy-runtime/LegacyGameCanvas.tsx (or wherever new Application() lives), make the very first Pixi-related lines:
TypeScript

// MUST be the first pixi import in this module (and ideally the app entry that loads the game)
import "pixi.js/unsafe-eval";

import { Application, Texture /* other pixi imports */ } from "pixi.js";


Then keep your existing boot:
TypeScript

const app = new Application();
await app.init({
  background: "#1a0f08",
  resizeTo: hostRef.current ?? undefined,
  antialias: true,
  // optional: preference: "webgl"  // force WebGL if WebGPU causes issues
});


Order is critical. The side-effect import must run before any Application / Renderer construction.
Also add it at the top of any other file that creates a Pixi Application (scene renderer, package entry, etc.).
After deploying this single change, the “We couldn’t open the Legacy world” error should disappear on CSP-restricted environments.

2. Harden Runtime Separation (App vs Game)
Keep the Niakofa community app and the Legacy Game cleanly separated while still sharing Family Vault data.
Recommended structure (already partially present):
text

artifacts/pay-it-forward/
  src/
    legacy-runtime/          ← game-only (Pixi, movement, combat, fishing, world)
      LegacyGameCanvas.tsx
      ...
    lib/legacy-world/        ← pure data (locations, activities, mutations)
    pages/legacy-*.tsx       ← thin React shells only


Rules
Layer	Owns	Must NOT own
React shell (pages/, journal UI, Family Vault UI)	Auth, journal display, quest list, high-level events	requestAnimationFrame, hitboxes, Pixi ticker, collision
legacy-runtime/ (Pixi)	Continuous world, movement, camera, weather, fishing runtime, combat, NPCs	Direct Family Vault writes, React state
Bridge	onQuestCompleted, onCombatOutcome, onWorldMutation, player position	Simulation logic

Export a tiny public API from the runtime:
TypeScript

// legacy-runtime/index.ts
export { LegacyGameCanvas } from "./LegacyGameCanvas";
export type { LegacyGameBridge } from "./bridge-types";


React pages only mount <LegacyGameCanvas bridge={...} /> and react to bridge callbacks. Never put game-loop code in React components.
