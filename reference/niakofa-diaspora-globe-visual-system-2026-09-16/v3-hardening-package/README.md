# Niakofa Diaspora Globe V3 reference

This reference copy records the V3 hardening package used for the Globe
iteration in September 2026. The source attachment is
`Niakofa_Diaspora_Globe_V3_Hardening_(1)_1789569222989.zip`.

V3 preserves the Globe → Hub → Action hierarchy and adds only:

- a quieter compact search dock;
- a reset-to-worldwide control;
- live marker state from `live_user_count`;
- explicit active-now Hub context;
- contextual U.S. state sibling navigation;
- a browser QA checklist and read-only geography audit.

The original uploaded ZIP remains available in `attached_assets/`.
