Bottom line

Yes — your instinct is correct about the interaction model, but I would call it an "immersive Stories viewer," not a Reels tab.

The important discovery is that Niakofa already has most of the difficult Story technology. We don't need to rebuild Stories from scratch.

We need to turn:

Story rail + Story page + modal viewer

into:

Story destination → immersive full-screen viewer → continuous Story navigation

while keeping the Story rail as the discovery/selection mechanism on Home.

And the current GitHub inspection also confirms that the previous five-icon Community navigation redesign has not actually landed on main yet. The repo is still carrying the six-tab shell and global Create button.

That means the next Community pass should address both together:

Community shell simplification + immersive Facebook-style Stories destination, rather than adding another tab/button.
