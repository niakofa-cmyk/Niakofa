Request Center now knows the user's role

The important function is:

getRequestNavigationPath(...)

It makes the decision centrally:

active + current user = helper
        → /request/:id

active + current user = requester
        → /request/:id/track

otherwise
        → /request/:id/view

That is the right architecture.

Helper reaches requester
