What I changed

The new architecture is now:

Diaspora → Globe → Diaspora Hub → Action

Instead of /diaspora behaving like a dashboard full of competing sections, it now centers the Globe and lets the user drill into a Hub.

Compact Hub actions:

Existing Family, Oral History, Legacy and full Globe experiences preserved

One important architectural boundary

I deliberately did not invent a second messaging system or second financial ledger just to make the Hub UI appear complete.

The Connect action currently enters the existing Community surface. Dedicated:

Hub A → Hub B conversation

and

County Pool → County Pool / Diaspora Hub funding

should connect to Niakofa's existing audited messaging and Community Pool accounting infrastructure rather than creating parallel sources of truth.

That is the safer production architecture.
